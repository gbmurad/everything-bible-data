# Everything Bible: Bible text downloads

These files are the Bible texts that the Everything Bible iPhone app downloads on request. Each file is the text of one
published translation, converted to the app's format (a JSON list of books, chapters and verses, packed as a raw DEFLATE
stream). The app checks each file against a SHA-256 recorded inside the app before it installs it.

The text of each Bible belongs to its own publisher, under the license given below. Nothing here is original to the app.
